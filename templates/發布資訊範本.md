# 發布資訊範本（YouTube／Facebook／Instagram）

> 用法：作品預覽或成片驗收通過後，複製本檔成 `output/<作品>/發布資訊.md`（放在作品資料夾最上層，與各版本子資料夾同層）；將 `<…>` 換成實際內容，刪除不適用的段落。
> 每個作品只有一份發布資訊，文案以選定的發布版本（通常是最新定稿版）為準；其他版本只列在〈版本一覽〉當演進素材，不各寫一份。換發布版本時改寫這一份，不另存新檔。
> 本檔提供發布文案與內部檢查欄位；填完後由使用者選定文案並發布。平台介面與規定會變，發布時請再確認官方說明。

## 0. 共用資訊

### 作品與交付版本（內部紀錄，不直接貼出去）

| 項目 | 內容 |
|---|---|
| 作品名稱／發布版本 | <作品名／v幾> |
| 展示主題 | <外觀、材質、組裝、運動、建模過程等> |
| 主檔 | <發布版本的 .blend，例如 `<版本資料夾>/scene.blend`> |
| 交付與驗收紀錄 | <發布版本的 report.md／影片驗證 JSON 等相對路徑> |
| 橫式影片 | <相對路徑；解析度、比例、fps、實測秒數；沒有則刪除> |
| 直式影片 | <相對路徑；解析度、比例、fps、實測秒數；沒有則刪除> |
| 展示圖片／輪播順序 | <相對路徑；封面、全景、細節、製作過程等> |
| 公開展示／下載連結 | <已確認能開啟的網址；沒有則刪除> |
| 預計發布平台／日期 | <YouTube／Facebook／Instagram；日期> |

影片與圖片留在各自的版本資料夾，本檔用相對路徑連過去；沿用該版唯一主檔，不為社群發布另存一份 `.blend`。`output/` 整個只走 GDrive，不進 Git。

### 版本一覽（有多個版本才保留；演進素材，不另寫文案）

| 版本 | 展示主題 | 現存媒體 |
|---|---|---|
| [<v1>](<版本資料夾>/report.md) | <一句話主題> | <圖片／影片相對路徑與規格> |
| **[<發布版本>](<版本資料夾>/report.md)** | <一句話主題> | 本文件的發布版本 |

拿舊版媒體發貼文時，文案要寫成該版實際內容，不可套用發布版本的成果說法。

### 製作方式與 AI 揭露（依實際流程填寫）

AI 協作撰寫 `bpy` 腳本、Blender 建模與渲染，以及 AI 直接生成圖片／影片，是不同的製作步驟。只描述本次確實使用的方式，不套用「全片皆由 AI 生成」。

```text
🤖 製作方式
本作品由 <作者名> 與 <實際協作的 AI 工具> 協作，以 Blender 建模、設定材質、燈光與動畫，並由 Blender 渲染輸出。
<有生成素材時：背景／貼圖／配音／配樂由 <工具或模型名> 生成。>
<有克隆聲音時：配音使用本人錄音，或經 <姓名> 授權的錄音進行聲音克隆。>
```

### 使用的 AI 與工具

```text
🛠 使用工具
Blender（建模、材質、燈光、動畫與渲染）｜<Codex／Claude Code 等實際工具>（程式與製作協作）｜<剪輯或編碼工具>
<選填：實際生圖模型（用途）｜實際配樂模型（用途）｜ComfyUI（工作流）>
```

- 只列確實用到的工具與用途；生成素材要記實際模型，不能只寫執行工作流的介面。
- 與 `report.md`、片尾及其他平台的名單核對；無配音或配樂就刪掉對應項目。

### 參考素材與來源（有使用才保留）

```text
🔗 參考與素材
外觀參考：<作品／品牌／作者>｜<來源網址>（<參考範圍，例如僅外觀研究>）
使用素材：<模型、HDRI、貼圖、音樂等名稱>｜<作者>｜<來源網址>｜<授權及要求的標示>
```

只以公開照片研究造型時，照實寫「外觀參考」；使用第三方模型、拓樸、Rig 或貼圖時，另外記錄實際素材及授權。來源與授權依該作品的 `report.md` 核對。

### 展示範圍與限制（機械、角色研究等依作品選用）

```text
📌 作品說明
<機械展示：本作展示外觀、幾何接觸與運動學動畫；尚未驗證的製造公差、受力、實際走時等不在本次成果範圍。依本版完成程度改寫。>
<角色／品牌外觀研究：本作為個人 3D 造型研究，非官方作品；參考對象與素材來源見上方。>
```

描述須與本版驗收證據一致；「可製造」「物理模擬」「實際走時」等能力，須有相應驗證才能寫入文案。

## 1. YouTube

### 標題（提供 3–5 個候選，再選一個）

1. <作品名>｜從零件到組裝的 Blender 3D 展示
2. <吸睛細節或製作挑戰>｜<作品名／版本>
3. AI 協作 Blender：<本次完成的具體成果>

以本片確實展示的成果為主，版本名稱與封面一致。

### 說明欄（可直接貼；刪除佔位與不適用段落）

```text
<開場 2–4 行：這是什麼作品、最值得看的細節，以及這次完成了什麼。>

👉 <互動提問，例如：下一個想看哪個零件的近拍？>

📌 本次展示
<亮點一>
<亮點二>
<共用資訊的展示範圍與限制>

⏱ 章節（適用才保留，時間須依成片填寫）
0:00 <開場>
<分:秒> <段落二>
<分:秒> <段落三>

🤖 製作方式
<貼入共用資訊的實際製作方式與 AI 揭露>

🛠 使用工具
<貼入實際工具名單>

🔗 參考與素材
<有使用時貼入來源及署名>

🌐 更多作品：<公開展示網址>
🎬 頻道：<頻道名>
#Blender #3D動畫 #<作品主題>
```

- 章節為選用；手動章節須從 `0:00` 起，至少三段且每段至少十秒。短片不適用就刪除整段，依 [YouTube 章節說明](https://support.google.com/youtube/answer/9884579?hl=zh-Hant) 確認。
- 標籤欄可填：`Blender, 3D建模, 3D動畫, <作品名>, <主題詞>, <實際協作工具>`；與說明欄的 hashtag 分開填。

### 上傳設定與封面

| 項目 | 填寫／確認方式 |
|---|---|
| AI 使用／變造或合成內容 | 依實際生成內容與 [YouTube 官方揭露說明](https://support.google.com/youtube/answer/14328491?hl=zh-Hant) 判斷；包含配樂與聲音。AI 協作寫腳本本身不足以決定整支影片的標示。 |
| 兒童專屬內容 | 按目標觀眾與實際內容判斷。 |
| 封面 | 優先取本版正式渲染，選單一焦點、清楚細節與簡短標題；額外生成的概念圖須標明其性質。 |
| 字幕 | 有旁白或台詞時，核對繁中字幕與成片。 |
| Shorts | 優先調整 Blender 鏡位再輸出直式版，檢查主體完整、字幕與操作介面遮擋。 |

- Reels 使用直式構圖並在手機預覽；發布畫面若涉及 AI 生成素材，依 [Meta 官方標示說明](https://about.fb.com/news/2024/04/metas-approach-to-labeling-ai-generated-content-and-manipulated-media/) 與當下的揭露選項填寫。

## 5. 發布前檢查

- [ ] 發布版本正確；媒體與該版主檔、`report.md` 及驗證紀錄一致；〈版本一覽〉的連結都能開
- [ ] 影片已實際播放，確認畫面、音訊、時長與字幕；圖片已放大檢查
- [ ] 機械細節等主張有相應角度的預覽證據，文案的完成程度與限制符合實際成果
- [ ] 製作方式、AI 揭露、工具名單與片尾一致
- [ ] 素材及配樂已核對使用條件，必要的來源、署名及授權紀錄已補齊
- [ ] 各平台的 AI 揭露選項已按內容確認，未把所有 Blender 渲染一律寫成 AI 直接生成
- [ ] 封面、橫直版構圖、手機裁切及文字可讀性已檢查
- [ ] 章節時間與成片一致；不適用的段落與所有 `<…>` 佔位已刪除
- [ ] 連結可公開開啟，發布文字沒有私人路徑、個資或內部授權附件
- [ ] 使用者已選定最終文案與發布媒體
